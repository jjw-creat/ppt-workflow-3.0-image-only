# PPT 工作流 3.0｜使用指南

这份文档说明怎样从一个想法开始，得到保留完整生图效果的 PPT。

**3.0 的最终交付是只图版：每张完整图片是一页 PPT。** 页面里的文字、图形和照片都已经在图片中；修改发生在页面图片上，确认后重新组装 PPT。

## 1. 先选你的使用方式

| 你现在的情况 | 从哪里开始 |
|---|---|
| 想让助手设计、生成图片并交付 PPT | 第 2 节 |
| 想让助手写提示词，自己去其他工具生图 | 第 5 节 |
| 已经有完整的页面图片，只需要装成 PPT | 第 6 节 |
| 想修改已经做好的 PPT | 第 7 节 |

第一次使用时，将本仓库的 [SKILL.md](../SKILL.md) 交给助手阅读。能操作本地文件的助手可以直接读取仓库；其他环境可上传或粘贴技能内容。

图片生成需要所用环境具备生图能力，或者由你去其他工具生成。**仓库脚本只负责图片组装，不会自己调用生图模型。**

## 2. 给助手一份简短需求

至少说明：讲什么、给谁看、用来做什么。页数、文字和参考图有多少就提供多少；没有明确风格时让助手先设计候选方向。

可以直接复制下面这段：

> 使用 PPT 工作流 3.0，只做只图版。  
> 主题：秦岭生态与生物多样性。  
> 用途：面向公众的自然科普介绍。  
> 听众：学生和普通观众。  
> 篇幅：约 6 页。  
> 我想表达：秦岭的山地环境、森林与水、代表性物种，以及生态保护的意义。涉及真实知识请先核对来源，生成画面标注“视觉示意”。  
> 请先整理逐页文案，再用同一份内容做 3 张不同风格的完整页面供我选择。选定后延展整套，每张原图直接作为一页 PPT。不要拆图层或重建可编辑文字。

如果你提供参考资料，顺便说明它的用途：

> 这些照片是要放进页面的实际素材；这两张参考 PPT 只参考配色和构图；这份文字中的名称和数字必须准确保留。

不要把真实成果和设想混在一起。没有实验数据、订单、获奖或客户时，按方案设想表达，不让助手补造。

可选：使用 [项目说明模板](../templates/brief.md) 保存这些内容。不需要填写多份表格。

## 3. 看三个方向，只选视觉方向

助手会用同一份内容制作约 3 张完整页面。这些应当已经包含文字、主视觉和布局，不是只有背景的壁纸。

选择时主要看：

- 哪张最符合场合和受众？
- 哪张的标题、重点和正文容易读？
- 哪张的照片或图形能帮助解释内容？
- 是否愿意让整套 PPT 延续这种风格？

你可以这样回复：

> 选 A。保留它的摄影感、深绿色和暖金色。正文比现在大一点，后面的科普页要更清楚。继续制作。

也可以组合反馈，但要指明优先级：

> 以 B 为主，只借用 A 的配色，不要混用两套字体和图标风格。

已经有明确选中的方向，就沿用，不必每页重新选一次。

## 4. 延展整套并确认终稿

选定风格后，先看两类页面：一张以场景或照片为主，一张信息较密。这一步用来判断同一种风格能否支撑不同内容。

两类页面看起来合适后，继续其余页面。最终每张图都要包含该页需要的文字、页码、标注和来源；组装时不会自动补这些元素。

你可以这样推进：

> 沿用选定风格，把第 2 页做成山地环境场景，第 3 页讲森林与水的关系。确认文字清楚、布局合适后继续其余页面，最后组装只图版 PPT。

最后检查：

1. 页数和讲述顺序是否正确。
2. 名称、数字、单位和中文有没有错误。
3. 正文在整页缩略图下是否仍然可读。
4. 是否有被裁掉的文字、错误图示或多余标签。
5. 整套的配色、字体层级和图片风格是否协调。

修改要求尽量具体：

> 第 3 页把右下角正文放大，并删去重复的副标题。其他文字、配色和布局保持不变，另存一个新版本。

终稿确认后发送：

> 用确认后的页面原图，按 01 到 06 的顺序生成只图版 PPT，并保留原图和提示词。

## 5. 我自己去生图，助手只给提示词

先对助手说：

> 使用 3.0 只图版。这次先不要生图，请给我逐页可复制的完整提示词。每条都要包含准确文案、主视觉、版式、风格、参考图用途和统一的画面比例。我生成后再把原图交回来组装。

每次生成时，把相关参考图实际上传给生图工具；在提示词里写一个本地文件名，并不等于工具已经看到那张图。

生成后：

1. 下载原始图片文件，尽量不要用聊天窗口截图代替。
2. 检查所有页面的方向和比例一致，建议统一 16:9。
3. 只挑最终确认的版本，按页码命名。
4. 将原图交给助手，明确页序和要修的地方。

可直接发送：

> 这些是已经确认的页面原图，文件名就是页序。请检查图片尺寸和页数，然后生成 3.0 只图版 PPT，不做 OCR、拆层和文字覆盖。

## 6. 已有图片：一条命令组装

下面是自己运行脚本的方法；也可以把文件和目标位置交给助手操作。

### 首次准备

需要 Python 3.10 或更新版本。下载本仓库，进入仓库目录后运行：

```bash
python -m pip install -r requirements.txt
```

现有环境已装好依赖时无需重复安装。组装不需要 PowerPoint 或生图 API Key。

### 整理文件

```text
my-project/
├── brief.md
├── drafts/                 # 未选方案、旧版本，不放进终稿目录
└── slides/                 # 这里只放每页唯一的最终图片
    ├── 01_封面.png
    ├── 02_问题.png
    └── 03_方案.png
```

支持 PNG、JPG、JPEG。目录模式按自然文件名顺序读取，1、2、10 不会排成 1、10、2。

### 生成 PPT

在仓库根目录运行：

```bash
python scripts/images_to_pptx.py "my-project/slides" -o "my-project/output/final.pptx"
```

也可以明确列出顺序：

```bash
python scripts/images_to_pptx.py "cover.png" "problem.png" "solution.png" -o "output/final.pptx"
```

已有同名文件时，建议另存为新版本：

```bash
python scripts/images_to_pptx.py "my-project/slides" -o "my-project/output/final_v02.pptx"
```

确定要替换已有 PPT 时，才添加 `--force`。

### 用仓库自带示例试一次

```bash
python scripts/images_to_pptx.py examples/agri-remote-sensing/slides -o output/demo.pptx
```

脚本会验证每页只有一张图片，而且 PPT 内保存的图片与源文件字节一致。原图不会在组装时被重新编码。

## 7. 修改已经做好的 PPT

只图版推荐按这个顺序修改：

> 找到对应页面原图 → 修改或重新生成那一张图 → 用新图替换终稿目录中的对应页 → 重新组装并另存 PPT

例如：

> 把第 4 页的标题“珍稀动物”改成“代表性物种”，其他内容保持不变。修改原图后替换第 4 页，再输出 final_v02.pptx。

请保留每页原图和完整提示词。只有 PPT 文件时，也可以提取里面的图片再修改，但直接保存源图更方便。

不要在 3.0 中用可编辑文字框覆盖旧文字：这会重新引入字体和位置不一致，也可能让旧字残留。确实需要逐字编辑时，单独使用可编辑工作流。

## 8. 常见问题

| 问题 | 处理方法 |
|---|---|
| 文字太小、内容挤 | 缩短文案或拆成两页，再修改完整图 |
| 中文出现错字 | 对该页进行定向修改，确认文字后重新组装 |
| 原图就模糊 | 回到生图阶段提高源图质量；PPT 组装不会增加细节 |
| 报 Different aspect ratio | 页面比例不一致，按统一比例重新导出；大比例差异不会被脚本强行拉伸 |
| 报 Output exists | 换一个输出文件名，或确认替换后用 --force |
| 报 Invalid image | 检查文件是否下载完整、是否真的是静态 PNG/JPEG |
| JPEG 提示 EXIF rotation | 在图片工具中按正确方向导出无旋转标记版本 |
| 页数比预期多 | slides 中混入了旧版本或未选方案，把它们移到 drafts |
| 在 PPT 里改不了字 | 这是只图版的预期行为，按第 7 节修改页面图片 |

## 9. 三种题材的启动示例

**博物馆介绍**

> 做一套 6 页的博物馆介绍，使用 3.0 只图版。先以陕西历史博物馆为例，面向普通观众，讲历史脉络、代表性文物和观看文物的方法。核对文物名称、时代和馆藏归属，不把生成图片当成真实馆藏照片。先给展陈摄影、纸本考古、现代图文三种完整页面风格供我选择。

**红色文化宣传**

> 做一套 6 页的红色文化介绍，使用 3.0 只图版。以延安的历史记忆与文化传承为切入点，面向普通公众。核对事件、时间、旧址和引用来源，不虚构历史照片。先给庄重纪实、纸本档案、现代主题海报三种完整页面风格供我选择。

**秦岭生态**

> 做一套 6 页的秦岭生态科普，使用 3.0 只图版。重点讲山地环境、森林与水、代表性物种和生态保护。先核对地理与物种知识，不编造统计数字；生成画面注明视觉示意。先给自然纪录片、博物学图录、现代生态信息图三种完整页面方向。

如果同时制作多套 PPT，分别开对话、分别保存项目目录，在对应对话里选择风格；不要把不同主题的草稿混到同一个 slides/ 目录。

## 10. 最后应拿到什么

- 一份只图版 PPT。
- 按页码排列的最终原图。
- 项目说明和生图 / 修改提示词。
- 简短检查说明：页数、顺序、原图一致性，以及是否实际打开或渲染过 PPT。
